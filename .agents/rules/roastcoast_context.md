# Контекст и правила проекта RoastCoast

## 1. Описание проекта
- **Заказчик:** RoastCoast (производитель и обжарщик кофе, сайт roastcoast.ru).
- **Главная концепция (Zero-Touch Sales):** Автономные продажи без участия менеджера — клиент сам выбирает кофе, помол/фасовку, оформляет СДЭК и оплачивает онлайн.
- **Единый бэкенд:** Учёт товаров, цен, остатков и заказов происходит в **МойСклад ERP**. Сайт — это витрина.

## 2. Ключевые компоненты
1. **Каталог B2C (`index.html`):** Розничный интернет-магазин с фильтрацией по вкусам, помолу, способу заваривания и доставкой СДЭК.
2. **Личный кабинет оптовика B2B (`b2b.html`):**
   - Быстрый оптовый заказ по матрице товаров (200г / 1000г, зерно/помол).
   - Прогрессивные скидки (-25% ... -40%) от оптового объема.
   - Скачивание/генерация счетов на оплату и УПД.
3. **Интеграционный слой:** Прослойка кэширования для API МойСклад (Rate Limits) и СДЭК API v2.

## 3. Файлы документации в репозитории
- `project_summary_for_gemini.md` — полное описание требований, логики и вопросов для встречи с клиентом.
- `b2b.html` — готовая интерактивная верстка личного кабинета оптовика.
