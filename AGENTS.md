# ROASTCOAST PROJECT INSTRUCTIONS & CONTEXT

## Overview
This repository contains the web application and B2B portal for **RoastCoast** (coffee roaster).

## Project Principles & Core Tech
1. **Zero-Touch Sales:** Autonomous customer purchases (B2C & B2B) without requiring manager phone calls.
2. **MoySklad Integration:** Single source of truth for stock, prices, and orders is MoySklad ERP.
3. **B2B Portal (`b2b.html`):** Fast bulk matrix ordering interface (200g / 1000g, grain / grind options), volume discount calculation (25-40%), invoice generation.
4. **B2C Website (`index.html`):** Retail catalog with flavor descriptors, SCA scores, CDEK shipping calculator.
