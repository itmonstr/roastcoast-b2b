# RoastCoast — B2B Личный кабинет оптовика & Презентация

Интерактивный B2B-портал для кофейной обжарочной компании **RoastCoast** (Севастополь).

## 🚀 Онлайн-демонстрация (GitHub Pages)

- **B2B Оптовый Портал:** [Открыть b2b.html](https://itmonstr.github.io/roastcoast-b2b/b2b.html)
- **Интерактивная презентация логики проекта:** [Открыть презентацию](https://itmonstr.github.io/roastcoast-b2b/)

## 📦 Функционал B2B Портала
- **Каталог сортов кофе:** Фирменные бленды и микролоты свежей обжарки.
- **Два режима отображения:** Карточки товаров и табличная оптовая матрица с удобным выбором фасовки (`200 г`, `1 000 г`).
- **Автоматический расчёт оптовой скидки:** -30% от розничной цены.
- **Индикатор минимального заказа:** Шкала прогресса до 10 кг для оптовых условий.
- **Формирование счёта на оплату:** Модальное окно с реквизитами поставщика (Севастополь, ул. Правды, 28) и условиями доставки (СДЭК по всей России).
- **Экспорт оптового прайс-листа:** Быстрая выгрузка в формате CSV/Excel.
